## Project Overview

**Murshid Mini** is an educational LLM application engineering project developed as part of the **LLM Application Engineering (SDA-AIE-213)** training program, with acknowledgment to **SDAIA Academy** and the **Data and Artificial Intelligence Center of Excellence (DAICO)** at **King Saud University (KSU)**.

The project demonstrates the design, implementation, testing, and evaluation of an LLM-style application using Python and Google Colab.

The core application uses a simulated language model (FakeClient) and synthetic data to demonstrate fundamental LLM application engineering concepts without relying on external AI APIs.

## Project Features

- Arabic and English FAQ support.
- Structured application-status requests.
- Read-only tool integration.
- Input validation and authorization checks.
- Safety guardrails and input protection.
- Golden test suite with 10 test cases.
- Exact-match caching for public FAQ responses.
- Performance measurement and execution metrics.
- JSON-based reporting and evaluation.

## Project Development

The project was developed across four labs:

| Day | Implementation |
|---|---|
| Day 1 | Application foundations, FakeClient, and response validation |
| Day 2 | Structured tool calls, validation, and authorization |
| Day 3 | Safety guardrails, input validation, and golden testing |
| Day 4 | Caching, performance metrics, cost estimation, and final evaluation |

## How to Run

1. Open `notebooks/MurshidST.ipynb` in Google Colab.
2. Select a Python 3 runtime with CPU.
3. Run all 14 code cells sequentially.
4. Review the results generated by each lab.
5. Check the evaluation results and JSON reports.
6. Download the generated files from the `murshid_outputs` folder.

The core project does not require a paid API key or GPU.

## Evaluation Results

The final evaluation produced the following results:

| Metric | Result |
|---|---|
| Golden Tests Passed | 10/10 |
| Pass Rate | 100% |
| Mock Calls Without Cache | 3 |
| Mock Calls With Cache | 1 |
| Cache Hit Rate | 66.7% |
| External API Calls | 0 |
| Hypothetical Cost per Request | $0.0036 |

The caching experiment demonstrated a reduction in repeated mock-client calls for identical public FAQ requests.

The estimated cost is hypothetical and is included for educational purposes only. No actual external API charges were incurred.

## Limitations

- The core project uses a simulated language model rather than a live LLM.
- All application records are synthetic.
- Real user authentication is not implemented.
- Routing is based on a finite set of predefined rules.
- Guardrails are educational demonstrations.
- The application is not intended for production deployment.
